GUIDE UTILISATEUR - CLIENT S-EXPRESSION

    Démarrage : Lancez d'abord SExpressionServer, puis SExpressionClient.

    Interface :

        La zone centrale permet de saisir des scripts complexes.

        Les boutons en haut permettent de générer instantanément des formes (Cercle, Rectangle) sur le serveur et le client.

    Comparaison : Une fenêtre "[Server]" s'ouvrira pour valider que le rendu distant est identique au rendu local "[Client]".

    Raccourcis : Le bouton "Exécuter" envoie tout le contenu de l'éditeur au serveur via HTTP
